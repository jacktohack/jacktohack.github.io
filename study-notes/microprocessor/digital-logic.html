1. Combinational and Sequential Digital Logic

Created 30 September 2026 · Last edited 30 September 2026

Digital logic provides fundamental building blocks for modern microprocessors. It is commonly divided into combinational logic and sequential logic. Combinational circuits produce outputs from their current inputs without storing state; gates, muxes, and demuxes are examples. Sequential circuits store state, so their outputs depend on both current inputs and previously stored values. Flip-flops and registers are examples: they normally update on clock edges, though an asynchronous reset can change stored bits without a clock edge.

1. Combinational logic uses current inputs

1.1 Logic gates perform Boolean operations

These operators act on single bits:

Gate Expression Output is 1 when…
NOT ~a a is 0
AND a & b Both inputs are 1
OR a | b Either or both inputs are 1
XOR a ^ b Inputs differ

1.2 Multiplexers select one data input

A multiplexer (mux) passes one selected input to its output; it stores nothing. A two-input example is y = (~s & a) | (s & b): select 0 passes a, select 1 passes b.

                   E
                   |
                   v
             +-----------+
    a ------>|0          |
    b ------>|1          |
    c ------>|2         y|------> y
    d ------>|3          |
             |           |
             |     S     |
             +-----------+
                   ^
                   |
                s1 s0
               (2 bits)

The two select bits choose which input to copy to y: s1 s0 = 00 chooses a, 01 chooses b, 10 chooses c, and 11 chooses d. E is an active-high enable: the mux works when E = 1, so y copies the selected input. When E = 0, the mux is disabled and y = 0, regardless of the select bits or input values. To build this 4-to-1 mux from gates, two NOT gates produce ~s1 and ~s0; four AND gates each check one select pattern and E, and an OR gate combines their outputs:

In the drawing, * means two wires are connected; wires that merely cross without * are not. For example, when s1 s0 = 01 and E = 1, only the b gate has all its select and enable inputs equal to 1, so its output equals b. The other three AND outputs are 0; the OR gate therefore makes y = b. If b = 0, then y = 0 too. When E = 0, every AND gate receives a 0 from E, so y = 0 for any selection.

1.3 Demultiplexers route data to one output

A demultiplexer (demux) takes one input, y, and sends its value to just one of four outputs (a, b, c, or d). The select bits choose the destination. Every output not selected stays at 0. For example, if s1 s0 = 01, then b = y and a = c = d = 0; if y = 0, all four outputs are 0.

             +-----------+
             |          0|------> a
    y ------>|          1|------> b
             |          2|------> c
             |          3|------> d
             |           |
             |     S     |
             +-----------+
                   ^
                   |
                s1 s0
               (2 bits)

The select bits choose the output that copies y: 00 chooses a, 01 chooses b, 10 chooses c, and 11 chooses d. The other three outputs stay at 0. In the gate drawing below, the two NOT gates make ~s1 and ~s0 (the opposites of s1 and s0). Each AND gate receives y plus the select signals for one choice. For example, the b gate computes y AND ~s1 AND s0: when s1 s0 = 01, that becomes y AND 1 AND 1 = y.

     s1  s0                 y
      |   |                 |
      *---|--[NOT]--+       |
      |   |         |~s1    |
      |   *--[NOT]--|---+   |
      |   |         |   |~s0|
      |   |         |   |   |   +-----+
      |   |         *---|---|-->|     |
      |   |         |   *---|-->| AND |----> a
      |   |         |   |   *-->|     |
      |   |         |   |   |   +-----+
      |   |         |   |   |
      |   |         |   |   |   +-----+
      |   |         *---|---|-->|     |
      |   *-------------|---|-->| AND |----> b
      |   |             |   *-->|     |
      |   |             |   |   +-----+
      |   |             |   |
      |   |             |   |   +-----+
      *---|-------------|---|-->|     |
      |   |             *---|-->| AND |----> c
      |   |                 *-->|     |
      |   |                 |   +-----+
      |   |                 |
      |   |                 |   +-----+
      *---|-----------------|-->|     |
          *-----------------|-->| AND |----> d
                            *-->|     |
                                +-----+

Unlike the mux, the demux has four separate outputs, so there is no OR gate combining them. For example, when s1 s0 = 01, b copies y while a, c, and d are 0. If y = 0, then b is also 0—all four outputs are 0.

2. Sequential logic stores state over time

2.1 Flip-flops store one bit

Each D flip-flop stores one bit. When clk changes from 0 to 1 (a rising edge), it copies its D input to its Q output. Between rising edges, Q keeps its previous value. These two flip-flops have no enable (E) input.

A signal is active-high if 1 turns it on, and active-low if 0 turns it on. The small circle and the name resetn mean this reset is active-low: resetn = 0 clears both flip-flops to Q0 Q1 = 00; resetn = 1 allows normal operation. In the conventional flip-flop symbol used here, the separate top reset pin denotes a direct asynchronous clear: asserting resetn = 0 clears the outputs without waiting for a clock edge. The circle itself tells us only the active-low polarity.

                +----------------------------------------------+
                |                                              |
 resetn --------|-------------------*--------------+           |
                |                   |              o           |
                |                   |       +-------------+    |
                *---[NOT]o----------|------>| D         Q |----*---> Q0
                |                   |       |             |
                |                   |   +-->|>    FF0     |
                |                   |   |   +-------------+
                |                   +---|----------+
                |                       |          o
                |     +-------+         |   +-------------+
                +---->|       |         |   |             |
                      |  XOR  |---------|-->| D         Q |----*---> Q1
                +---->|       |         |   |             |    |
                |     +-------+         *-->|>    FF1     |    |
                |                       |   +-------------+    |
 clk -----------|-----------------------+                      |
                |                                              |
                +----------------------------------------------+

Q0 feeds the NOT gate and one XOR input; Q1 feeds the other XOR input. These wires loop back to determine the next stored values.

Q0 flips on every rising clock edge because its next value is D0 = ~Q0. Q1 gets D1 = Q1 ^ Q0, where ^ means XOR. If the old Q0 is 0, Q1 ^ 0 = Q1, so Q1 stays the same. If the old Q0 is 1, Q1 ^ 1 = ~Q1, so Q1 flips. Both flip-flops use their old outputs at the same clock edge; neither uses the other flip-flop’s new value. For example, from Q1 Q0 = 01, the next Q1 is 0 ^ 1 = 1 and the next Q0 is ~1 = 0, so the new state is 10.

Old Q1 Q0 New Q1 Q0
00 01
01 10
10 11
11 00

Starting from reset (00), the states repeat 00 -> 01 -> 10 -> 11 -> 00. The two stored bits count from 0 to 3 and then return to 0 (modulo 4). For both flip-flops, D determines what bit to store next, while the shared clk determines when to store it: D0 = ~Q0 and D1 = Q1 ^ Q0. With reset inactive, changing an input to D does not immediately change its stored Q. For example, the first clock edge changes Q1 Q0 from 00 to 01. That new Q0 = 1 changes the value waiting at Q1’s D input, but Q1 remains 0 until the next rising edge, when the state becomes 10. Both flip-flops use the same clock, so the counter is synchronous.

2.2 Registers store multiple bits

A register stores several bits together—here, Q3 Q2 Q1 Q0. A mux before each flip-flop selects the data it will store. With reset inactive, the register acts on each rising edge of clk:

  • Load (E = 1, s_l = 1): copy D3 D2 D1 D0 into Q3 Q2 Q1 Q0 together.
  • Shift (E = 1, s_l = 0): put din into Q3; each other bit takes its neighbour’s old value (Q3 -> Q2 -> Q1 -> Q0).
  • Hold (E = 0): keep the stored bits unchanged, even at a rising edge.

Between clock edges, changing E, s_l, or the data inputs does not change the stored bits. Asynchronous reset is the exception: resetn = 0 clears them without waiting for an edge.

                             Q3                       Q2                       Q1                       Q0
                              ^                        ^                        ^                        ^
                              |                        |                        |                        |
resetn ---------------*-------|----------------*-------|----------------*-------|----------------+       |
                      o       |                o       |                o       |                o       |
                 +---------+  |           +---------+  |           +---------+  |           +---------+  |
             +-->|D       Q|--*       +-->|D       Q|--*       +-->|D       Q|--*       +-->|D       Q|--+
             |   |         |  |       |   |         |  |       |   |         |  |       |   |         |
E -----------|-->|E--------|--|-------|-->|E--------|--|-------|-->|E--------|--|-------|-->|E        |
             |   |         |  |       |   |         |  |       |   |         |  |       |   |         |
clk ----*----|-->|>        |  |  +----|-->|>        |  |  +----|-->|>        |  |  +----|-->|>        |
        |    |   +---------+  |  |    |   +---------+  |  |    |   +---------+  |  |    |   +---------+
        +----|----------------|--*----|----------------|--*----|----------------|--+    |
         +---+---+            |   +---+---+            |   +---+---+            |   +---+---+
         | MUX   |<+          |   | MUX   |<+          |   | MUX   |<+          |   | MUX   |<+
         | 0   1 | |          |   | 0   1 | |          |   | 0   1 | |          |   | 0   1 | |
         +-------+ |          |   +-------+ |          |   +-------+ |          |   +-------+ |
           ^   ^   |          |     ^   ^   |          |     ^   ^   |          |     ^   ^   |
           |   |   |          +-----+   |   |          +-----+   |   |          +-----+   |   |
           |   |   *--------------------|---*--------------------|---*--------------------|---+
           |   |   |                    |                        |                        |
          din D3  s_l                  D2                       D1                       D0

All four flip-flops receive the same E, clk, and resetn. All four muxes receive the same s_l: port 0 selects the shift path (din into Q3, then each old Q into the next stage), while port 1 selects the parallel inputs D3 D2 D1 D0.

resetn E s_l When Resulting Q3 Q2 Q1 Q0
0 X X Immediately 0000 (reset)
1 0 X At a rising clock edge Unchanged (hold)
1 1 1 At a rising clock edge D3 D2 D1 D0 (load)
1 1 0 At a rising clock edge din, old Q3, old Q2, old Q1 (shift)

X means either 0 or 1: those controls do not matter in that row. For example, if Q3 Q2 Q1 Q0 = 1010 and din = 1, one enabled shift changes the register to 1101; the old Q0 leaves the four stored bits. s_l chooses whether shift data or parallel-load data is waiting at each flip-flop’s D input. E decides whether the flip-flops may store that data. Changing either signal does not immediately change Q3 Q2 Q1 Q0; the register waits for the next rising edge of clk. Reset is different: resetn = 0 clears the stored bits to 0000 without waiting for a clock edge.
